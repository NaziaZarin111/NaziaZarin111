# Nazia Zarin

**Computational biology researcher** · MS in Biochemistry & Biotechnology, University of Barishal, Bangladesh

I build end-to-end *in silico* pipelines — differential gene expression, network pharmacology, molecular docking, and molecular dynamics — to identify **biomarkers** and **repurposable drugs** for cancers and comorbid diseases. Currently a Research Assistant under Dr. Shaila Haque, with an MS thesis on an integrated computational framework for colorectal cancer.
